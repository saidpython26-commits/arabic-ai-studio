# FreeGen AI Studio (استوديو الذكاء الاصطناعي المحلي)

استوديو ويب محلي متكامل ومفتوح المصدر بالكامل (Local-First)، يعمل على جهازك دون الحاجة إلى أي مفاتيح API مدفوعة أو اتصالات خارجية. يتيح لك الدردشة المتدفقة فائقة السرعة مع نماذج الذكاء الاصطناعي المفتوحة، وتوليد تطبيقات كاملة مبنية على Next.js 14 مع محرر كود ومعاينة حية وتصدير ZIP.

---

## 💻 متطلبات التشغيل والعتاد (Hardware Requirements)

- **الحد الأدنى للبطاقة الرسومية (GPU):** 8GB VRAM (مثل NVIDIA RTX 3060 / 4060 أو معالجات Apple Silicon M1/M2/M3).
- **وضع المعالج المركزي (CPU Fallback):** في حال عدم توفر كرت شاشة مخصص، يعمل النظام تلقائياً عبر المعالج المركزي (CPU-only fallback) باستخدام نماذج خفيفة مدمجة.
- **الذاكرة العشوائية (RAM):** 16GB RAM كحد أدنى موصى به.
- **المساحة التخزينية:** 15GB لتخزين أوزان النماذج وقواعد البيانات المحلية.

## 🚀 تثبيت Ollama وتحميل النماذج (Models Setup)

### 1. تثبيت Ollama
قم بتحميل وتثبيت Ollama لنظام تشغيلك (Linux / macOS / Windows) عبر:
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 2. تنزيل النماذج المطلوبة
قم بتشغيل السكربت التلقائي المتوفر في المستودع:
```bash
chmod +x infra/ollama/pull-models.sh
./infra/ollama/pull-models.sh
```
أو سحبها يدوياً:
```bash
# نموذج المحادثة الأساسي (8GB VRAM)
ollama pull llama3.1:8b

# نموذج التضمين واسترجاع المستندات (RAG)
ollama pull nomic-embed-text

# نموذج توليد الأكواد البرمجية
ollama pull qwen2.5-coder:7b
```

## 🐳 تشغيل النظام بالكامل (Deployment & Run)

### الخيار الأول: التشغيل السريع عبر Docker Compose
يتم تشغيل واجهة Next.js، وخادم FastAPI، و Redis، و Ollama بأمر واحد:
```bash
docker compose -f infra/docker-compose.yml up -d --build
```
- واجهة الاستوديو: `http://localhost:3000`
- خادم واجهات البرمجة (FastAPI): `http://localhost:8000/docs`
- خادم Ollama: `http://localhost:11434`

---

### الخيار الثاني: التشغيل المحلي للتطوير (Local Development)

#### 1. خادم الواجهات الخلفية (FastAPI):
```bash
cd apps/api
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

#### 2. واجهة المستخدم (Next.js 14 / Vite):
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```
افتح المتصفح على `http://localhost:3000`.

## 📖 دليل الاستخدام السريع

### 1. المحادثة الذكية والبحث في المستندات (Chat & RAG)
- انتقل إلى تبويب **المحادثة (Chat)**.
- اسأل نموذج `llama3.1:8b` باللغة العربية أو الإنجليزية واستمتع باستجابة متدفقة فورية (SSE).
- اضغط على أيقونة المشبك **(رفع ملف)** لرفع ملفاتك الخاصة (`.pdf`, `.docx`, `.txt`).
- يقوم محرك التضمين `nomic-embed-text` بتقسيم الملف وتوليد المتجهات في جدول SQLite للربط المعرفي التلقائي مع المحادثة.

### 2. مولد التطبيقات (Next.js 14 App Generator)
- انتقل إلى تبويب **مولد التطبيقات (App Generator)**.
- اكتب وصف فكرة تطبيقك (مثال: *"تطبيق إدارة مهام تفاعلي مع لوحة إحصائيات ووضع داكن"*).
- اضغط على **توليد التطبيق الكامل**.
- يُنشئ النظام مشروعاً كاملاً بهيكل Next.js 14 + Tailwind CSS + TypeScript.
- تصفح الملفات، حرّر الكود مباشرة في محرر الأكواد، وشاهد التغييرات في **المعاينة الحية (Live Sandbox)**.
- تواصل مع المشروع عبر صندوق التعديل الذكي (مثال: *"أضف صفحة تسجيل الدخول"*).
- اضغط **تصدير كملف ZIP** لتحميل مشروعك الكامل على جهازك!
